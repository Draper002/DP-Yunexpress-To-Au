## 已完成

### 业务流程

- 第 1 步：DP 订单 CSV 转云途批量寄件模板。
- 第 2 步：云途或顺丰国际订单信息转 DP 发货回填模板。
- 第 3 步：云途根据运单号和 SKU 分拣；顺丰根据每页面单的寄方姓名拆分。
- SKU 文件夹命名：`日期+SKU+申报中文名+数量`。
- 每个 SKU 文件夹同时包含 PDF 和供应商 ZIP。
- 单个 SKU 文件夹不放发货明细表。
- 操作结果按发货日期保存。

## 当前已知限制

- Windows、Mac 和 Web 的入口已经分开，业务脚本统一位于 `shared/fulfillment/`。
- 多个脚本各自定义输出路径，尚未抽取为共享模块。
- Mac 固定配置路径沿用桌面版自动识别逻辑，尚未在 Mac 实机验证持久化体验。
- Tkinter 可以实现接近 OS 26 的配色和层级，但无法实现完整原生液态玻璃效果。
- 没有 Apple Developer 账户，因此当前 Mac 版本只能先做本机测试和临时签名。
- Web 处理仍为单机同步执行，适合低并发；高并发需要任务队列、PostgreSQL 和对象存储。
