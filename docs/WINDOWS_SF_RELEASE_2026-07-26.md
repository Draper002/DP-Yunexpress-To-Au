# Windows 顺丰国际版本说明

更新时间：`2026-07-26 19:15 CST (Asia/Shanghai)`

## 使用步骤

1. 打开 `DP&Yunexpress To Au.exe`。
2. 在第 1 步选择“顺丰国际”。
3. 选择本次 DP 订单 CSV。
4. 在“固定配置”中确认 SKU 商品库和 `BatchImportOrders_V39.xlsm`。
5. 明确选择顺丰业务类型以及是否带电。
6. 点击“开始生成”，成功后直接打开结果文件夹。
7. 顺丰后台创建订单成功后，下载“顺丰订单数据”文件。
8. 进入第 2 步，选择“顺丰国际”及本次顺丰订单数据，生成 DP 发货回填文件。
9. 下载顺丰合并面单 PDF，进入第 3 步选择“顺丰国际”，按寄方姓名拆分。

## 当前范围

- 已支持：DP 订单 CSV 转顺丰国际批量上传 `.xlsm`。
- 已支持：顺丰国际订单数据 `.xls/.xlsx` 转 DP 发货回填 `.xlsx`。
- 保留顺丰原始模板的工作表、样式、下拉验证和包结构。
- 已用 12 单虚构数据完成字段级、工作簿结构和超预留行数测试。
- 顺丰第 1 步已通过实际后台上传验证。
- 顺丰第 2 步已用 246 单实际导出验证：订单号和运单号无空值、无重复，承运商全部为 `SF INTERNATIONAL`。
- 顺丰第 3 步已用 246 页面单验证：识别到 2 个寄方，输出 245 页和 1 页两个合并 PDF。
- 第 3 步按面单文字中的“寄方姓名”分组，不依赖订单表、SKU 商品库或人工排序。
- 待您验证：将第 2 步生成文件上传 DP 后台。

## 第 2 步字段映射

```text
顺丰“客户订单号” -> DP Order ID
固定值“SF INTERNATIONAL” -> DP Carrier
顺丰“顺丰运单号” -> DP Tracking Number
```

## 安全要求

不要将真实订单、买家姓名、地址、电话、面单或输出文件上传到 GitHub。
