# 同收件人同 SKU 合单发布说明

更新时间：`2026-07-30 21:35 CST (Asia/Shanghai)`

## 业务规则

- 仅处理 `processing` 状态且一个订单只有一个 SKU 的 DP 订单。
- 收件人姓名、街道、城市、州、邮编、电话标准化后一致，并且 SKU 完全一致时，才属于同一合并组。
- 不同 SKU、不同收件信息、不同承运平台或不同批次不会合并。
- 合并组使用确定性客户单号 `MYYMMDDNNN`；原始 DP 订单号和数量完整保存在合单计划中。
- 合单计划绑定原始 DP CSV SHA-256、发货日期和承运平台，第二、三步不匹配时直接停止。

## 三步输出

1. 第 1 步按真实包裹数生成云途或顺丰上传模板，并生成“订单合并关系”Excel/JSON。
2. 第 2 步要求承运商导出中每个客户单号只有一个唯一运单，再把该运单展开写入组内全部原始 DP 订单；同时生成“合并订单与运单对应表”。
3. 第 3 步把合并面单从普通 SKU 或寄方分组中移除，放入独立“合并件”目录。每组包含一张面单、`合并订单说明.xlsx` 和一个供应商 ZIP。

## 防错边界

- 普通订单重复运单号仍会报错。
- 一个运单跨越两个合并编号会报错。
- 承运商客户单号、原始 DP 订单集合、面单运单集合或 SKU 不一致会报错。
- 合并面单不会重复出现在普通供应商文件中。
- 软件无法判断实体仓库是否真的把多个订单装入同一包裹，供应商仍需按合并说明核对总数量。
