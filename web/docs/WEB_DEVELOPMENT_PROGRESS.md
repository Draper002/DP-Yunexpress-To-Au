# 网页版本开发进度

更新时间：`2026-07-26 21:10 CST (Asia/Shanghai)`

## 当前状态

Web 版已完成云途和顺丰国际三步工作流，属于可部署测试版。业务逻辑统一来自 `shared/fulfillment/`，Windows、Mac 和 Web 不维护重复字段映射。

## 已完成

- FastAPI 后端与响应式工作台，支持云途/顺丰国际逐步骤切换。
- 管理员与员工账号；管理员创建员工并维护固定配置。
- 每个员工只显示自己的处理记录，也不能下载其他员工的结果。
- 固定配置支持 SKU 商品库、云途标准模板、顺丰国际标准模板和 DP 发货模板。
- 固定配置可以单独替换一份，无需重复提交其他模板。
- 云途第 1 步：DP CSV 生成云途批量寄件 Excel。
- 云途第 2 步：云途订单信息生成 DP 发货回填模板。
- 云途第 3 步：面单 ZIP 按 SKU 整理，并返回供应商总压缩包。
- 顺丰第 1 步：DP CSV 生成顺丰 XLSM，业务类型和是否带电由用户明确选择。
- 顺丰第 2 步：顺丰 `.xls/.xlsx` 生成 DP 回填模板，承运商固定为 `SF INTERNATIONAL`。
- 顺丰第 3 步：合并面单 PDF 按“寄方姓名”拆分，并返回总压缩包。
- 两个平台使用独立批次目录，避免用户切换平台后误用上一批文件。
- 脚本执行增加进程内互斥锁，避免并发请求修改共享命令参数。
- 提供 `/healthz`、Docker 非 root 用户和 Compose 健康检查。

- 2026-07-26 使用实际结构的顺丰 DP CSV、顺丰模板、SKU 库、订单 `.xls` 和面单 PDF 完成 Web 三步回归。

## 批次与数据规则

- 批次文件位于 `data/working/<user_id>/<platform>/`。
- 结果位于 `data/results/<user_id>/<date>/<platform>/`。
- 第 3 步成功后清理对应平台的批次文件；失败时暂时保留以便排查。
- SQLite、固定配置和结果目录必须挂载到持久化磁盘并纳入备份。
- Web 单文件上传上限为 80 MB；反向代理建议允许 100 MB，并设置至少 300 秒超时。

## 上线前仍需处理

- 必须启用 HTTPS，并保持 `DP_WEB_COOKIE_SECURE=1`。
- 增加登录限流、CSRF 防护、密码重置、员工停用和安全审计。
- 增加失败批次及历史结果的自动过期清理。
- 高并发使用场景应改用后台任务队列、PostgreSQL 和私有对象存储。
- 首次服务器部署先使用脱敏文件小批量验收，再处理真实订单。
