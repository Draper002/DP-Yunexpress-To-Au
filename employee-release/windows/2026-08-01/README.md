## 使用方法

1. 下载 ZIP 到 Windows 电脑。
2. 先完整解压，不要直接在压缩包内运行。
3. 双击 `DP&Yunexpress To Au.exe`。
4. 员工首次使用时，在“固定配置”中选择 SKU 商品库及物流模板。

该压缩包不包含真实订单、买家信息、面单或账号配置。
