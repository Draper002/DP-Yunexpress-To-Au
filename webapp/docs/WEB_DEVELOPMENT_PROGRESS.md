# 网页版本开发进度

更新时间：`2026-07-11 12:05 CST (Asia/Shanghai)`

## 已完成的 MVP

- FastAPI 网页后端，复用现有三个 Python 发货脚本。
- 管理员与员工角色，管理员可创建员工账号。
- 固定配置上传和替换：SKU 商品库、云途标准模板、DP 发货模板。
- 第 1 步上传 DP 订单 CSV，生成云途上传 Excel。
- 第 2 步上传云途订单信息 Excel，沿用本批次第 1 步文件生成 DP 回填模板。
- 第 3 步上传全部面单 ZIP，沿用本批次文件按 SKU 分拣并返回总压缩包。
- 处理记录保留状态、步骤、发货日期、结果路径、校验报告路径和时间戳。
- 原始文件写入本批次临时目录；第 3 步完成或失败后删除批次临时目录。
- 浅色雾蓝、系统蓝强调色的网页工作台界面。
- 本地启动和登录后工作台页面检查通过。

## 当前批次规则

第 1 步后，DP 订单 CSV 临时保存在 `webapp/data/working/<user_id>/`；第 2 步继续使用该文件；第 3 步使用 DP CSV、云途订单信息和面单 ZIP 完成匹配后清理临时目录。用户不需要在第 2、3 步重复上传前面的文件，同时原始文件不会作为长期结果保存。

## 当前限制

- MVP 目前在 Web 请求中同步执行，大文件或多员工同时处理时需要改为后台任务队列。
- 数据库为 SQLite，适合单机或低并发云服务器；正式扩展建议使用 PostgreSQL。
- 结果文件暂存于服务器本地磁盘；正式部署建议使用私有对象存储和下载授权。
- 需要补充 CSRF 防护、登录限流、密码重置、员工停用、审计日志和自动过期清理。
- 需要配置 HTTPS、反向代理、域名、备份和监控后才能正式公网使用。
- 当前网页接口尚未接入真实模板和订单测试，不应直接用于生产订单。
